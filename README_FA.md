# سپندار سیستم توانا — مرکز دانلود حرفه‌ای

## امکانات
- طراحی فارسی راست‌چین و واکنش‌گرا با هویت سپندار
- صفحه عمومی جست‌وجو و دسته‌بندی فایل‌ها
- لینک دانلود مستقیم و شمارنده دریافت‌ها
- پنل مدیریت، آپلود چند فایل، دسته‌بندی، توضیح، عمومی/خصوصی‌سازی، کپی لینک و حذف
- نوار پیشرفت واقعی درصد آپلود، حجم ارسال‌شده، حجم کل و سرعت لحظه‌ای
- اعلان آغاز دانلود برای مشتری

## درصد پیشرفت دانلود مشتری
برای فایل‌های تا 200 مگابایت، صفحه دانلود درصد واقعی دریافت، حجم دریافت‌شده و سرعت تقریبی را در اعلان شناور نشان می‌دهد. چون این روش فایل را در حافظه مرورگر جمع می‌کند، برای فایل‌های بزرگ‌تر از 200 مگابایت دانلود مستقیم عادی مرورگر استفاده می‌شود تا از مصرف زیاد حافظه جلوگیری شود. نوار پیشرفت آپلود نیز درصد، حجم و سرعت ارسال واقعی را نشان می‌دهد.

## اجرای ویندوز
1. Python 3.11+ را نصب کن و Add Python to PATH را فعال کن.
2. ZIP را استخراج کن.
3. `run_windows.bat` را اجرا کن.
4. مرورگر را به `http://127.0.0.1:5000` ببر.
5. ورود اولیه آزمایشی: `admin` / `ChangeMe-123!`

قبل از انتشار عمومی رمز و SECRET_KEY را تغییر بده. رمز اولیه عمومی و آزمایشی است؛ این نسخه اولیه قابلیت تغییر رمز از پنل را ندارد، پس قبل از استفاده عمومی آن را تکمیل کن.

## دامنه
نام‌های پیشنهادی برای بررسی ثبت (موجود بودنشان تضمین نشده):
- `files.sepandarsystemtavana.ir`
- `cloud.sepandarsystemtavana.ir`
- `download.sepandarsystemtavana.ir`
- `sepandarsystemtavana.com`

برای انتشار، دامنه/زیردامنه، هاست با ذخیره‌سازی دائمی، HTTPS و اجرای برنامه با سرور تولیدی نیاز است. اجرای محلی به‌تنهایی لینک عمومی ایجاد نمی‌کند. پشتیبان‌گیری از پوشه `data` را تنظیم کن. قبل از انتشار عمومی، تغییر رمز مدیر، محدودیت تلاش ورود، ثبت رویداد و اسکن فایل‌ها را اضافه کن.

## انتشار آزمایشی رایگان روی Render
این پروژه فایل `render.yaml` و `Procfile` برای استقرار آزمایشی دارد.
1. یک حساب رایگان در GitHub بساز و وارد شو.
2. پروژه را به‌صورت یک مخزن جدید در GitHub بارگذاری کن.
3. در Render گزینه New + → Blueprint را انتخاب و مخزن را متصل کن.
4. سرویس `sepandar-cloud` را ایجاد کن؛ آدرس رایگان با پسوند `onrender.com` ساخته می‌شود.
5. پس از اولین اجرا، مقدار متغیر `ADMIN_PASSWORD` را در Environment سرویس پیدا کن و آن را محرمانه نگه دار.

**هشدار مهم درباره پلن رایگان:** این استقرار فقط برای آزمایش است. دیسک و پایگاه داده محلی این برنامه روی پلن رایگان Render ماندگار نیستند؛ فایل‌های آپلودشده و اطلاعات پنل ممکن است پس از استقرار مجدد یا راه‌اندازی مجدد از بین بروند. فعلاً فایل حساس یا مهم مشتریان را روی آن نگه ندار. برای مرکز دانلود واقعی، فضای ذخیره‌سازی پایدار لازم است که ممکن است رایگان نباشد.
